# 0006. MIT license

- Status: accepted
- Date: 2026-10-26

## Context

The repo is public and meant to be reused and forked. It mixes code (build scripts), data (tokens) and prose (guidelines). My principles repo uses CC BY 4.0, which suits documents but is not recommended for software. Knowledge Automata uses Apache 2.0.

## Decision

MIT for the whole repo: short, permissive, and common for design tokens and design systems.

## Consequences

- Anyone can fork and adapt it, keeping the copyright notice.
- Fonts are not covered: Lora and Inter keep the SIL Open Font License 1.1 and will carry their own license file when added to `assets/fonts/`.
- Personal marks (the chef hat) will need a note if added to `assets/icons/`, since a personal mark is not something I want reused as someone else's identity.
